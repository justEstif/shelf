📚 Shelf

Your files.
One binary.

A single-user file hosting app. Upload files, browse them publicly, manage from a dashboard. Ships as one self-contained Go binary with zero runtime dependencies.

View on GitHub

Public file browser

Browse and download files, navigate folders. Clean, minimal interface that works on any device.

Single binary, zero deps

Static files embedded. No Node.js, no npm, no runtime. Download the binary, set a password, run. Or pull the Docker image.

JSON API

Upload, list, and delete files via Bearer token auth. Script your workflow with curl or any HTTP client.

One command. Up and running.

# Docker
docker run -p 3000:3000 \
-e SHELF_PASSWORD=secret \
-e CSRF_KEY=this-is-exactly-32-bytes-long-x! \
-v shelf-pages:/shelf/pages \
-v shelf-data:/shelf/data \
ghcr.io/justestif/shelf
# Binary
wget https://github.com/justEstif/shelf/releases/latest/download/shelf-linux-amd64
chmod +x shelf-linux-amd64
SHELF_PASSWORD=secret CSRF_KEY=this-is-exactly-32-bytes-long-x! ./shelf-linux-amd64
